# NextLvlStock

Sistema de gestión y control de inventario desarrollado con Laravel, Vue.js, Docker y MySQL.

## Objetivo

Construir una aplicación que permita administrar:

- Productos
- Categorías
- Marcas
- Bodegas
- Proveedores
- Clientes
- Compras
- Ventas
- Movimientos de inventario
- Roles y permisos
